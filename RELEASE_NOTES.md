# История изменений (Release Notes)

## Версия 0.2.7 (2026-10-23)

*Воспроизведение всего выделения из Проводника и номера треков без обрезания.*

### 🐛 Исправления

- Кнопка «Воспроизвести» в Проводнике передаёт весь список выбранных треков без искусственного ограничения количества файлов.
- Большие списки передаются через файл запроса, обходя ограничения длины командной строки и размера IPC-сообщения.
- Исправлена гонка при быстром подтверждении запроса работающим плеером.
- Номера от100 и более длинные полностью помещаются в столбце: учитываются шрифт, отступы темы и текстовые поля Qt, в том числе после сортировки и фильтрации.

### 🛠 Улучшения

- Системный обработчик выбора включён в сборку и установщик; существующие приложения по умолчанию сохраняются.

### ✅ Проверки

- Проверяются холодный запуск с256 треками, добавление301 трека в работающий плеер и отдельная передача16000 путей.
- Проверяется отображение номеров в плейлистах из104 и1004 треков.

## Версия 0.2.6 (2026-10-22)

*Открытие всего выделения из Проводника без ограничения количества треков.*

### 🐛 Исправления

- Команды открытия и воспроизведения получают всё выделение через COM, без старых ограничений Windows в 15 или 100 файлов.
- Большие списки передаются через файл запроса, поэтому не обрезаются ограничениями командной строки и IPC-сообщения.
- Устранена гонка подтверждения передачи: уже отправленные данные больше не считаются ошибкой при быстром ответе работающего плеера.
- Путь к выбранной пользователем копии AudioPlayer и приложения по умолчанию сохраняются.

### ✅ Проверки

- Системный COM-обработчик проверяется на выделениях свыше100 файлов и длины командной строки, при холодном запуске и работающем плеере.
- Большой IPC-запрос проверяется на16000 путей без обрезания списка.

## Версия 0.2.5 (2026-10-22)

*Сортировка плейлистов, запоминание последней папки и оставшееся время без смещения звуковой волны.*

### ✨ Новые возможности

- Щелчок по заголовку №, «Название», «Формат» или «Время» сортирует очередь; повторный меняет направление. У каждой вкладки своя сортировка.
- Диалоги открытия файлов, добавления музыки и выбора папки используют последнюю выбранную папку, включая после перезапуска.
- Красные цифры справа от волны показывают остаток времени. Правый щелчок переключает на полную длительность; каждый новый трек автоматически включает остаток.

### 🐛 Исправления ошибок

- Ширина столбцов подбирается по содержимому: трёхзначные номера треков помещаются полностью.
- Номер, формат и длительность, включая заголовки, выровнены по центру; названия — по левому краю.
- Переключение времени сохраняет ширину метки и звуковой волны. Остаток отображается без минуса.
- Сортировка сохраняет воспроизводимый файл и выделение; двойной щелчок, удаление и следующий трек соответствуют видимому порядку.

### ✅ Проверки

- Проверки сортировки, поиска, числовой длительности, сохранения папки и переключения времени дополняют тесты реального воспроизведения и повторных запусков.
- Сборка Windows проходит проверку происхождения DLL и неинтерактивную проверку воспроизведения без показа окон.

## Версия 0.2.4 (2026-10-20)

*Открытие музыки из Проводника в одном плеере, плейлисты текущего сеанса и обложки из папки.*

### ✨ Новые возможности

- При отсутствии обложки в тегах используется изображение из папки трека: cover, folder, front, затем остальные изображения по имени. Повреждённые и недоступные файлы пропускаются.
- При открытии нескольких файлов из Проводника запускается один экземпляр плеера. Все выбранные файлы добавляются по имени с учётом чисел; первый начинает играть.
- Повторное открытие файлов передаёт их работающему плееру; запуск без файлов возвращает его окно.

### 🐛 Исправления ошибок

- Открытие аудиофайла из Проводника запускает воспроизведение, в том числе если трек уже есть в списке.
- Одновременные запуски больше не создают несколько окон и не перезаписывают настройки друг друга.

### 🛠 Изменения поведения

- Содержимое плейлистов хранится только до закрытия плеера. Списки из старых настроек игнорируются.
- Названия вкладок, активная вкладка, громкость и геометрия окна по-прежнему сохраняются.

### ✅ Проверки

- 131 тест: воспроизведение, одновременные запуски, передача файлов, повторные запуски и обложки.
- Сборка Windows проверяется без показа окон с декодированием аудио и проверкой нативных библиотек.

## Версия 0.2.3 (2026-10-20)

*Плейлисты содержат только треки текущего сеанса.*

### 🛠 Изменения поведения

- Содержимое плейлистов больше не сохраняется между запусками. Старые списки в настройках игнорируются.
- Названия вкладок, громкость и геометрия окна сохраняются.
- Файлы из Проводника и добавленные вручную остаются в текущем сеансе.

## Версия 0.2.2 (2026-10-20)

*Выделенные в Проводнике файлы открываются в одном экземпляре плеера.*

### ✨ Возможности

- Один экземпляр на пользователя: повторные запуски передают файлы уже работающему плееру.
- Отдельные запросы Проводника объединяются в пакет; файлы сортируются по названию с учётом чисел, запускается первый.
- Запуск без файлов возвращает существующее окно из свёрнутого состояния.

## Версия 0.2.1 (2026-10-20)

*Исправлено автоматическое воспроизведение файлов, открытых из Проводника.*

### 🛠 Исправления

- Запуск с путём к аудиофайлу добавляет его в выбранный плейлист и сразу начинает воспроизведение.
- Уже добавленные файлы не дублируются; из нескольких переданных путей запускается первый доступный аудиофайл.

## Версия 0.2.0 (2026-10-20)

*Несколько независимых плейлистов, тексты песен из тегов и более удобное управление компактным плеером.*

### ✨ Возможности

- Вкладки плейлистов: добавление кнопкой «+», закрытие правым кликом, сохранение треков и выбранной вкладки.
- Поиск по названию в выбранном плейлисте и отдельная очередь воспроизведения при просмотре других вкладок.
- Тексты песен из встроенных тегов и кнопки изменения размера шрифта с сохранением выбора.
- Четыре режима: остановиться после трека, повтор трека, плейлист один раз, плейлист по кругу.
- Стрелки ←/→ перематывают на 5 секунд, Home/End меняют трек, пробел переключает паузу.

### 🎨 Интерфейс

- Нижняя панель плейлиста: поиск слева, действия справа, стабильная ширина счётчика и единый шрифт 17 px.
- Левый счётчик времени показывает/скрывает плейлист; правый открывает текст песни и повторным кликом скрывает панель.
- Логотип закрепляет окно поверх остальных; переключение без мерцания и смещения.
- Перетаскивание за все края и углы плейлиста; ширина плеера и положение сохраняются между запусками.
- Кнопка воспроизведения выровнена по центру волны, всплывающие подсказки отключены.

### 🛠 Исправления

- Восстановление позиции непосредственно под верхней панелью задач без лишнего отступа.
- Остановка возвращает время и волну к началу; закрытие чужого плейлиста не прерывает музыку.
- Колесо на себя увеличивает громкость, от себя уменьшает её.

### 📦 Поставка

- Windows x64, переносимая папка и русский установщик; настройки при обновлении сохраняются.

## Версия 0.1.0 (2026-10-18)

*Первый выпуск компактного аудиоплеера для Windows со звуковой волной и локальным плейлистом.*

### ✨ Возможности

- MP3, FLAC, WAV, OGG/OGA, Opus, M4A (AAC/ALAC), AAC, WMA, AIFF/AIF, APE и WavPack.
- Перемотка по волне щелчком и колесом, фоновое построение и кеширование волны.
- Плейлист, повтор трека и очереди, A–B и случайный порядок.
- Обложка, теги и параметры аудио, управление через системный лоток.

### 🎨 Интерфейс

- Компактное графитово-оранжевое окно и пристыковываемый плейлист.
- Настройки шага перемотки, оригинальная иконка и единые значки управления.

### 📦 Поставка

- Windows x64, переносимая папка программы и русский установщик.
- Исходники приложения под MIT; лицензии сторонних компонентов включены отдельно.
